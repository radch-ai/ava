# Project Package

The project package provides centralized project metadata and build information for the Nevaria AI Agent Gateway. It maintains a single source of truth for project identifiers, versioning, and descriptive metadata used throughout the application.

## Overview

- **Single Source of Truth**: All project metadata defined in one place
- **Build-Time Versioning**: Version injected at build time
- **Code Generation**: Metadata auto-generated from project configuration
- **Exported Constants**: Readable identifiers for name, slug, description, module path, and binary name

## Quick Start

```go
import "github.com/nevaria-ai/gateway/internal/project"

// Access project metadata
fmt.Printf("Project: %s\n", project.Name)
fmt.Printf("Description: %s\n", project.Description)
fmt.Printf("Version: %s\n", project.Version)
fmt.Printf("Module: %s\n", project.ModulePath)
fmt.Printf("Binary: %s\n", project.BinaryName)
```

## Usage Examples

### Display Version Information

```go
func printVersion() {
    fmt.Printf("%s v%s\n", project.Name, project.Version)
    fmt.Printf("%s\n", project.Description)
    fmt.Printf("Module: %s\n", project.ModulePath)
}
```

### Build Version Injection

The Version variable is designed to be set at build time using ldflags:

```bash
# Build with version
go build -ldflags="-X 'github.com/nevaria-ai/gateway/internal/project.Version=v1.0.0'"

# Or via Makefile
make build VERSION=v1.0.0
```

### CLI Help Text

```go
func printHelp() {
    fmt.Printf("%s - %s\n\n", project.Name, project.Description)
    fmt.Printf("Usage: %s [options]\n", project.BinaryName)
    // ... help text
}
```

### User-Agent Header

```go
func getUserAgent() string {
    return fmt.Sprintf("%s/%s", project.Slug, project.Version)
}

// Example: "nevaria-gateway/1.0.0"
```

## Architecture

The project package is intentionally minimal:

```
internal/project/
└── details.go        # All project constants (code-generated)
```

### Code Generation

The `details.go` file is generated by `scripts/generate-project-details.go` from a parent `project-details` file. This ensures consistency across multiple repositories in the Nevaria ecosystem.

## Constants Reference

| Constant | Type | Value | Description |
|----------|------|-------|-------------|
| `Name` | string | `"Nevaria"` | Human-readable project name |
| `Slug` | string | `"nevaria"` | URL-friendly identifier |
| `Description` | string | `"AI Agent Gateway"` | Short project description |
| `ModulePath` | string | `"github.com/nevaria-ai/gateway"` | Go module import path |
| `BinaryName` | string | `"nevaria-gateway"` | Output binary filename |
| `Version` | string | `"dev"` (default) | Build version (set at compile time) |
