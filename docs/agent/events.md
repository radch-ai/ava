# Events

The agent framework supports comprehensive event types for real-time communication and monitoring. All events implement the `AgentEvent` marker interface.

## AgentEvent Interface

```go
type AgentEvent interface {
    isAgentEvent()
}
```

All event types implement this interface for type discrimination in event handlers.

## Event Types

### Agent Lifecycle Events

#### AgentStartEvent

Emitted when an agent starts processing a user message.

```go
type AgentStartEvent struct {
    Timestamp int64
}
```

#### AgentEndEvent

Emitted when an agent finishes processing. Includes the complete message history.

```go
type AgentEndEvent struct {
    Timestamp int64
    Messages  []AgentMessage
}
```

### Turn Lifecycle Events

#### TurnStartEvent

Emitted when a new turn (interaction cycle) begins. A turn represents one round of LLM interaction.

```go
type TurnStartEvent struct {
    Timestamp int64
}
```

#### TurnEndEvent

Emitted when a turn completes. Includes the final message and any tool results.

```go
type TurnEndEvent struct {
    Timestamp   int64
    Message     AgentMessage
    ToolResults []AgentMessage
}
```

| Field | Description |
|-------|-------------|
| `Timestamp` | Unix timestamp of turn end |
| `Message` | The assistant's response message |
| `ToolResults` | All tool result messages from this turn |

### Message Generation Events

#### MessageStartEvent

Emitted when a message starts being generated by the LLM.

```go
type MessageStartEvent struct {
    Timestamp int64
    Message   AgentMessage
}
```

#### MessageUpdateEvent

Emitted when streaming content is added to a message. This event fires multiple times during streaming.

```go
type MessageUpdateEvent struct {
    Timestamp int64
    Message   AgentMessage
    Delta     string
}
```

| Field | Description |
|-------|-------------|
| `Timestamp` | Unix timestamp of update |
| `Message` | Current message state with accumulated content |
| `Delta` | New content added since last update |

#### MessageEndEvent

Emitted when a message is complete and all content has been received.

```go
type MessageEndEvent struct {
    Timestamp int64
    Message   AgentMessage
}
```

### Tool Execution Events

#### ToolExecutionStartEvent

Emitted when a tool execution begins.

```go
type ToolExecutionStartEvent struct {
    Timestamp  int64
    ToolCallID string
    ToolName   string
    Args       map[string]any
}
```

| Field | Description |
|-------|-------------|
| `Timestamp` | Unix timestamp of start |
| `ToolCallID` | Unique identifier for this tool call |
| `ToolName` | Name of the tool being executed |
| `Args` | Arguments passed to the tool |

#### ToolExecutionUpdateEvent

Emitted when a tool produces partial results during execution. Useful for long-running tools.

```go
type ToolExecutionUpdateEvent struct {
    Timestamp     int64
    ToolCallID    string
    ToolName      string
    PartialResult any
}
```

| Field | Description |
|-------|-------------|
| `Timestamp` | Unix timestamp of update |
| `ToolCallID` | Tool call identifier |
| `ToolName` | Name of the tool |
| `PartialResult` | Partial result data |

#### ToolExecutionEndEvent

Emitted when a tool execution completes, whether successfully or with an error.

```go
type ToolExecutionEndEvent struct {
    Timestamp  int64
    ToolCallID string
    ToolName   string
    Result     any
    IsError    bool
}
```

| Field | Description |
|-------|-------------|
| `Timestamp` | Unix timestamp of completion |
| `ToolCallID` | Tool call identifier |
| `ToolName` | Name of the tool |
| `Result` | Result value or error details |
| `IsError` | True if execution failed |

## Event Flow

The complete event flow for a single user prompt:

```
1. User calls agent.Prompt(ctx, message)
2. AgentStartEvent emitted
3. TurnStartEvent emitted
4. MessageStartEvent emitted
5. MessageUpdateEvent emitted (multiple times for streaming)
6. MessageEndEvent emitted
7. (If tool calls) ToolExecutionStartEvent emitted for each tool
8. (If tool calls) ToolExecutionUpdateEvent emitted (optional, for long tools)
9. (If tool calls) ToolExecutionEndEvent emitted for each tool
10. TurnEndEvent emitted
11. AgentEndEvent emitted
```

## Subscription Example

```go
func handleAgentEvents(agent *Agent) {
    subID, events := agent.Subscribe()
    defer agent.Unsubscribe(subID)

    for event := range events {
        switch e := event.(type) {
        case AgentStartEvent:
            log.Printf("Agent started processing at %d", e.Timestamp)

        case TurnStartEvent:
            log.Printf("New turn started at %d", e.Timestamp)

        case MessageStartEvent:
            log.Printf("Generating response: %s", e.Message.Content)

        case MessageUpdateEvent:
            fmt.Print(e.Delta) // Stream response to console

        case MessageEndEvent:
            log.Printf("Message completed")

        case ToolExecutionStartEvent:
            log.Printf("Executing tool: %s with args: %v", e.ToolName, e.Args)

        case ToolExecutionUpdateEvent:
            log.Printf("Tool %s partial result: %v", e.ToolName, e.PartialResult)

        case ToolExecutionEndEvent:
            if e.IsError {
                log.Printf("Tool error: %v", e.Result)
            } else {
                log.Printf("Tool success: %v", e.Result)
            }

        case TurnEndEvent:
            log.Printf("Turn completed")

        case AgentEndEvent:
            log.Printf("Agent completed processing")
        }
    }
}
```

## Event Channel Buffer

Event channels are created with a buffer size of 100. If the buffer is full when emitting an event, the event is dropped for that subscriber. This prevents blocking on slow consumers.

```go
const defaultEventChannelBuffer = 100
```
